Remove the map image?

This can't be undone from Trash — you'll need to upload it again. Every place keeps its position.

Identity color, not a fill. Each place gets a 2px border + a ~10% wash from the six-color ACTIVITY_COLORS palette (cycled by sort order) — the same palette the schedule grid already uses as an identity dot, applied here as a border so the photo underneath stays visible. The label is a solid-ish chip (not a text-shadow halo) so it reads over any photo. Resize handle only appears on hover/drag (bronze, matches the schedule grid's own fill-handle convention); dragging either kind turns the outline navy — a universal "this is moving" signal, independent of the place's own identity color.
